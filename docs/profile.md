## Short Profile Framework

Create -> Restore -> Develop -> Provide -> Account -> Restrain -> Protect

For secular or civic audiences, the same ideas can be described as sustainability, recovery, human development, provision, accountability, responsible restraint, safety, continuity, dignity, and preservation.
